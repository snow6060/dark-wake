# 🛢️ Oil Chokepoint Intelligence & Multi-Agent Trading App

An institutional-grade intelligence platform combining IMF PortWatch daily maritime chokepoint telemetry (Strait of Hormuz, Bab-el-Mandeb) with a LangChain/LangGraph multi-agent market analysis debate.

## Quickstart
1. Copy `.env.example` to `.env` and configure your API keys.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `uvicorn main:app --reload`
